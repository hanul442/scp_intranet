# SCiPNET // SITE-19 TERMINAL

SCP 재단 인트라넷 느낌의 정적 팬 사이트. 콘텐츠는 SCP 재단 한국어 위키(scpko.wikidot.com)에서 가져오며 **CC BY-SA 3.0** 으로 배포됩니다. 각 문서 하단에 원 저자·역자·출처를 표기합니다.

**사이트 주소:** https://hanul442.github.io/scp_intranet/

## 구조
- `crawler.py` — scpko 위키에서 SCP 문서를 긁어 `data/scp.json` 생성 (`python3 crawler.py 173 049 ...`, `--series 1-3 --skip-existing` 으로 시리즈 목록 전체)
- `normalize.py` — 등급 표기 정리(취소선 소실, `유클리드/잠재적 케테르` 등)와 위키 잔여물 제거. 빌드할 때 자동 적용
- `src/index.html` · `src/style.css` · `src/js/*.js` — UI/로직 (파일 이름 순서대로 합쳐짐)
- `build.py` — src + data → `index.html` + `db/*.js`. `index.html` 에는 CSS·JS와 문서 색인(번호·제목·등급·태그·평가)만 인라인하고, 본문은 번호 50개 단위로 `db/` 에 나눠 문서를 열 때 불러옴. `--check` 는 결과물이 최신인지 확인만 함
- `index.html` · `db/` — 배포용 결과물 (둘을 같은 폴더에 두면 동작, `file://` 로 열어도 됨). 직접 수정하지 말고 `src/` 를 고친 뒤 빌드
- `tests/` — `python3 -m unittest discover -s tests`
- `.github/workflows/build.yml` — 테스트, `index.html` 최신 여부, 스크립트 문법 확인

## 문서 추가
```
python3 crawler.py 3001 1471 2000
python3 build.py
```

## 검색
데이터베이스 검색은 번호·제목·별명·태그를 바로 찾고, 본문은 이미 연 문서만 찾습니다. 결과 위의 '본문까지 검색' 버튼을 누르면 나머지 본문을 모두 불러와 다시 찾습니다.

## 주소
문서마다 주소가 있어 새로고침·뒤로가기·공유가 됩니다. `#scp-173`, `#scp-049/2`(부록), `#database?q=기억소거&c=keter`. 로그인 전에 열면 로그인 후 그 문서로 이동합니다.

## 세션 저장
같은 식별번호로 다시 로그인하면 권한 상향, 위반 횟수, 최근 열람, 읽은 메시지가 복원됩니다 (브라우저 localStorage).

## 그룹웨어 메뉴
- **전자결재** — 권한이 부족한 문서에 대해 *문서 열람 권한 신청*을 올리면 팀장 → 보안책임자 → RAISA 순서로 약 1분에 걸쳐 결재됩니다. 한 단계 위 문서까지 승인되고, 승인 후 24시간 동안 열람할 수 있습니다. *연차 휴가 신청*은 승인되면 일정에 표시됩니다.
- **근태 관리** — 출근·퇴근 버튼(홈 화면 카드에도 있음), 주간 근무시간과 주 52시간 막대, 지각·연장 표시, 남은 연차(휴가 결재와 연동).
- **회의실 예약** — 회의실 5곳의 날짜별 시간표(09–18시, 30분 단위), 빈 칸을 눌러 예약, 내 예약 취소. 보안 브리핑룸은 Level 3 이상.
- **일정** — 월간 달력. 기지 공통 일정(요일 규칙) + 내 일정 추가·삭제 + 승인된 휴가.
- **자료실** — 규정·서식·안내 문서 미리보기와 텍스트 사본 내려받기.
- **메일** — 받은편지함 · 보낸편지함 · 메일 쓰기 · 답장. 보낸 메일에는 잠시 뒤 상대방의 회신(부재 시 자동 응답)이 옵니다.
- **조직도** — 부서별 직원 목록, 검색, 내선(열람 사유 입력), 메일 바로 쓰기.
- **통합 검색** — 상단 검색창(`Ctrl+K`)이나 `find 검색어`: 문서 · 게시판 · 자료실 · 직원 · 메일을 한 번에.
- **알림 센터** — 상단 [알림]에 최근 알림 30건 보관.
- **게시판** — 공지사항 검색, 자유게시판 글쓰기·삭제(이 브라우저에 저장).
- **환경 설정** (상단 식별번호 클릭) — 화면 테마(기본/녹색/호박색/밝은 그룹웨어), 글자 크기, 효과, 자동 로그아웃 시간, 내 기록 초기화.
- **단축키** — `?` 도움말, `g` 다음 `h`/`d`/`m`/`b`/`a`/`c`/`o`/`r`/`i`/`s` 로 메뉴 이동.
- **격리 데이터베이스** — 50건씩 페이지, 등급·시리즈·태그 필터, 번호/평가/이름/최근 열람 정렬, 무작위 문서. 필터 상태는 주소에 남습니다.
- **문서 표지** — 문서마다 보안 등급 띠(비밀/제한/기밀/극비 색), 공문서 표지(항목 번호·격리 등급·문서 번호·개정판·관리 부서), 등급 아이콘과 색 띠로 문서를 구분합니다.
- **읽기 도구** — 문서 목차, 읽던 위치 기억(이어 읽기), 상단 진행 표시줄, 태그가 겹치는 비슷한 문서 6건, 날짜별 열람 이력(`#history`, `history` 명령).
- **문서 화면** — ☆ 즐겨찾기(대시보드·데이터베이스 필터에 표시), 글자 크기 가-/가+, 인쇄, 번호 순 이전·다음 문서.

## 보안 등급 규칙
- 식별번호가 `D-`로 시작 → Level 1, `DR-`/`MD-`/`R4-`/`L4-` → Level 3, 그 외 → Level 2, `O5...` → 거부
- 안전 1 / 유클리드 2 / 케테르 3 / 아폴리온·타우미엘·[데이터 말소] 4
- 커맨드라인 `override 05-13` → Level 4 (코드: 05-13, alpha-9, raisa, omega-7)
- 접근 거부 3회 누적 시 기억소거 경고

## 명령어
`help` `open 173` `search 케테르` `find 검색어` `list` `history` `whoami` `fx` `clear` `logout` `override <코드>` · `/` 키로 커맨드라인 포커스, `Esc`로 한 단계 위로, `↑`/`↓` 이전 명령
